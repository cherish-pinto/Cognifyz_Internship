# FormFlow - Complex Form Validation & Dynamic DOM Manipulation

A modern web application featuring advanced form validation, dynamic DOM manipulation, and client-side routing.

## Features

- **Complex Form Validation**: Username, email, password strength, phone number validation
- **Dynamic DOM Updates**: Real-time feedback on form inputs with visual indicators
- **Client-Side Routing**: Seamless navigation between Register, Profile, and Settings pages
- **Password Strength Meter**: Visual indicator showing password strength level
- **Local Storage**: Persist user data and preferences
- **Dark Mode**: Toggle dark mode in settings
- **Blue & Gold Theme**: Modern color scheme with smooth transitions

## Pages

1. **Register**: Create a new account with comprehensive validation
2. **Profile**: View saved user information
3. **Settings**: Manage notifications and dark mode

## Installation

1. Clone the repository
2. Open `index.html` in a modern web browser
3. Start registering and explore the application

## Validation Rules

- **Username**: Minimum 3 characters, alphanumeric and underscores only
- **Email**: Valid email format required
- **Password**: Minimum 8 characters with uppercase, lowercase, numbers, and special characters
- **Phone**: Valid phone number format with at least 10 digits
- **Terms**: Must accept terms and conditions

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge)
