# Task 1: HTML Structure and Basic Server Interaction

A simple web application demonstrating server-side rendering and form submissions using Express.js and EJS.

## Features

- HTML form with user input fields
- Express.js server with routing
- Server-side rendering with EJS
- Form submission handling
- Blue and gold color theme

## Installation

1. Install dependencies:
```bash
npm install
```

## Running the Application

Start the server:
```bash
npm start
```

The application will be available at `http://localhost:3000`

## How It Works

1. The home page displays a form where users can enter their name, email, and message
2. On submission, the form data is sent to the server
3. The server validates the input and renders the result page
4. The result page displays all submitted information

## Technologies Used

- Node.js
- Express.js
- EJS (Embedded JavaScript)
- HTML5
- CSS3
